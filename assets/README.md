# Assets

This directory contains game assets for Fantasy Chess.

## Directory Structure

- `images/` - Piece images, board graphics, and UI elements
- `sounds/` - Sound effects and background music

## Image Assets

### Pieces
Place piece images in the `images/` directory with the following naming convention:
- `white_king.png`, `black_king.png`
- `white_queen.png`, `black_queen.png`
- `white_rook.png`, `black_rook.png`
- `white_bishop.png`, `black_bishop.png`
- `white_knight.png`, `black_knight.png`
- `white_pawn.png`, `black_pawn.png`

### Fantasy Pieces
- `white_wizard.png`, `black_wizard.png`
- `white_dragon.png`, `black_dragon.png`
- `white_paladin.png`, `black_paladin.png`

### Board
- `board_light.png` - Light square texture
- `board_dark.png` - Dark square texture
- `portal_entry.png` - Portal entry visual effect
- `portal_exit.png` - Portal exit visual effect

## Sound Assets

Place sound files in the `sounds/` directory:
- `move.wav` - Piece movement sound
- `capture.wav` - Piece capture sound
- `check.wav` - Check notification sound
- `checkmate.wav` - Checkmate sound
- `portal.wav` - Portal teleport sound
- `special_ability.wav` - Special ability activation sound

## Asset Guidelines

- Images should be PNG format with transparency
- Recommended size: 128x128 pixels for pieces
- Sounds should be WAV or OGG format
- Keep file sizes reasonable for quick loading
