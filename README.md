# Fantasy Chess

A fantasy chess game with minimalistic shooting animations for unique chess-like pieces.

## Features

✨ **Five Unique Pieces with Shooting Animations:**
- 💣 **Pawn** (Robbanó lötty): Bomb-like trajectory with arc motion
- 🏹 **Bishop**: Arrow flight animation
- ⚡ **King**: Light beam effect with expanding glow
- 🪨 **Hobbit**: Sling projectile with spinning motion
- 🪓 **Dwarf**: Axe throw with rotation

🎮 **Interactive Gameplay:**
- Click pieces to see valid shooting targets highlighted in purple
- Smooth animations when pieces shoot
- Disappearing effects after animation completion

## Quick Start

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

Visit `http://localhost:5173` to play!

## How to Play

1. Click on a piece to select it (shown with blue highlight)
2. Valid shooting targets are highlighted in purple with pulsing effect
3. Click on a highlighted square to shoot and move the piece
4. Watch the animation as the projectile travels to the target
